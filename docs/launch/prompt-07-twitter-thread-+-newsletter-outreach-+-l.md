# Prompt 7: Twitter thread + newsletter outreach + LinkedIn

**Purpose:** T-5 teaser tweet, 6-tweet launch-day thread, 4 newsletter emails (Console.dev, TLDR Dev, Bytes, Cooperpress), T+24h LinkedIn reflection — all channels tuned to their audience and rhythm.

**Writes to:** docs/launch/social.md (archived); teaser to X at T-5d; thread to X at T+5min; LinkedIn post at T+24h; newsletter emails at T+12h.

---

## The prompt (paste into Claude/ChatGPT)

```
You are writing the T-5 to T+24h social/newsletter content for Claude Launcher's launch. Platforms and tone constraints below.

Produce:

1. T-5 DAYS TWITTER TEASER TWEET — standalone tweet, 20-second GIF attached (same as hero GIF), text ≤240 chars, NO LINK yet. Tone: "been building this, thoughts?" Example style: "been building this. Claude Launcher: run multiple Claude Desktop accounts side-by-side on Windows. first release dropping next Tue. drop a 👀 if you'd try it."

2. LAUNCH-DAY TWITTER THREAD — 6 tweets, numbered 1/6 through 6/6, each ≤280 chars:
   - 1/6: hero GIF + tagline + GitHub link + HN link
   - 2/6: the problem (Max 20x shared / work+personal / MCP dev isolated profiles) in one tight sentence
   - 3/6: how it works (3-sentence technical explanation naming --user-data-dir)
   - 4/6: screenshot of two Claude Desktops side-by-side (shot-two-up.png)
   - 5/6: honest limitations (Windows only, unsigned v0 with SmartScreen workaround documented, no auto-rotation ever)
   - 6/6: star + reply ask ("if this would save you from the sign-out dance, star the repo. Especially want to hear from Mac users — would you want a port?")

3. T+24H LINKEDIN REFLECTION POST (~300 words, personal-but-technical tone, no emoji flood) — raw numbers from first 24h (stars, HN points, comments, feedback themes), ONE specific user story, ONE honest thing that didn't go well, ONE thing I'd do differently. End with GitHub link.

4. NEWSLETTER OUTREACH EMAILS — 4 drafts, each ≤120 words, each with subject line:
   - Console.dev (submit form at https://console.dev/submit): one-para pitch + install link + hero GIF
   - TLDR Dev Newsletter (dev@tldrnewsletter.com): subject + 50-word blurb + GitHub link + HN thread link
   - Bytes (hi@bytes.dev): subject + 50-word blurb + GitHub link
   - Cooperpress (pick one — JavaScript Weekly or Node Weekly depending on which audience is closest): subject + 50-word pitch

Each email subject: if HN hit front page use "[Show HN front page] Claude Launcher — multi-account Claude Desktop for Windows"; if not, "New OSS Windows utility: Claude Launcher". No attachments except hero GIF inline.

Output: teaser + 6-tweet thread + LinkedIn + 4 newsletter emails, each clearly delimited with a header.
```
