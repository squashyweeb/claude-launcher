Shortcuts and tips

Keyboard

1-9Launch account N Shift+NClose account N Ctrl+NOpen account N's folder Ctrl+ShiftAAdd account Ctrl+LLaunch all Ctrl+WClose all F1This help EscDismiss dialog

Interactions

  • Right-click any card for Edit / Duplicate / Move / Who is signed in / Remove.
  • Each avatar has a keycap number in the bottom-right - press that key to launch.
  • The dashed tile at the bottom (or Ctrl+Shift+A) adds a new account.
  • In Add/Edit, "Detect identity" runs whois.py on the folder to auto-fill the fields.

Status

  • Gray dot = not running. Green dot = running (count shown).
  • Running cards get an accent-colored border and show RAM + uptime.
  • Auto-refresh runs every 2 seconds.
